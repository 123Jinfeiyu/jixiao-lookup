# jixiao-lookup · 绩效档次查询

单文件网页工具（零依赖、纯前端），输入两项分数即可算出综合绩效档位。

- **人效**：占 60%
- **原始成绩**：占 40%
- 结果区给出**综合档位**，页面底部附**完整映射表**便于核对

数据来源：档次表截图（2026-10-17）。全部计算在浏览器本地完成，不上传、不联网。

## 使用

直接用浏览器打开 `index.html` 即可；也可以部署到任意静态托管（GitHub Pages、Nginx、对象存储）。
